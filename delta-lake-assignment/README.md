# 🚀 Delta Lake Incremental Data Processing

This repository contains my **Delta Lake Assignment** demonstrating incremental data processing using Delta Lake and Databricks. The project covers loading data, cleaning records, performing MERGE operations, and validating the final dataset.

# 🎯 Project Objectives

- Load data into a Delta table.
- Perform basic data cleaning.
- Create an incremental dataset.
- Apply MERGE to update and insert records.
- Validate the final dataset.

# 🛠️ Technologies Used

- Databricks
- Delta Lake
- Apache Spark (PySpark)
- SQL

# ⚡ Concepts Covered

- Delta Tables
- Data Cleaning
- Incremental Data Processing
- MERGE Operation
- UPDATE & INSERT
- Data Validation
