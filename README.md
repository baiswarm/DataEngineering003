## About This Repository

This repository contains the work I completed during my **8-week Data Engineering internship at Celebal Technologies**.

It includes the weekly assessments, practical exercises, SQL and Spark tasks, cloud-based pipeline work, and the final data engineering project completed during the internship.

The work started with basic data handling and SQL and gradually moved towards **Azure Data Factory, Apache Spark, PySpark, Databricks, Delta Lake, and complete data processing pipelines**.
