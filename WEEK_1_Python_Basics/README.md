# Basic Data Exploration and Cleaning using Pandas
## Brief Summary
This project demonstrates basic data exploration and data cleaning using Python and Pandas. The dataset was loaded into a Pandas DataFrame, explored using various Pandas functions, cleaned by handling missing values and duplicates, and enhanced by creating a derived column. The cleaned dataset was then saved as a new CSV file.

## Steps performed during this task
- Loaded CSV dataset into a Pandas DataFrame
- Explored data using head(), tail(), shape, columns and data types
- Identified and handled missing values
- Performed filtering and column selection
- Checked and removed duplicate records
- Created a derived column (total_amount)
- Saved the cleaned dataset as a new CSV file named Updated_combined_dataset.csv
